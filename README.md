# SGA-DO: Sistema de Gestión Académica
### Diplomados Online - Proyecto Final

Repositorio oficial del núcleo (Backend) del Sistema de Gestión Académica desarrollado en tres lenguajes: Python, Java y C++.

## Estructura del Proyecto
- `/docs`: Documentación técnica, Plan de Acción, Diagrama UML e Informe Ejecutivo.
- `/python`: Implementación del prototipo funcional en Python.
- `/java`: Implementación orientada a objetos en Java con colecciones oficiales.
- `/cpp`: Implementación de alto rendimiento en C++ con gestión dinámica de memoria.
